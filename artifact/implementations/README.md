# Implementations — one directory per result

Each figure below is a comparison between one XPU-RT schedule and one ROS 2 deployment.
Its directory holds what the figure is, the command that rebuilds it, the small data behind
it, and pointers to the large data in `archive_v3/`.

Generated by `scripts/build_implementation_bundles.py`; `--check` fails if it and the
registries disagree.

## Implementations, one directory each

| tree | what is in it | how many |
|---|---|---|
| [`ros_deployments/`](ros_deployments/) | every ROS 2 arrangement measured on the K1 — what it runs, every rate it ran at, the command that re-measures it | 65 |
| [`xpurt_schedules/`](xpurt_schedules/) | every XPU-RT arm — the solved schedules the board executed, and the deployment points measured by hand | 43 |
| [`figures/`](figures/) | the audited comparisons, each drawing one arm from each tree | 6 |

A deployment with no figure is still here: what was measured and not drawn is part of
the comparison.
