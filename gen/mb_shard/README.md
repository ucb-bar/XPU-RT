# gen/mb_shard/ — per-width shard profiles for YOLO

YOLO's profile at shard widths 1, 2 and 4, from standalone board runs (`emit_shard_profile.py`), with the
matrix-engine tables added by `scripts/make_ime_profile.py`. `profile/provenance.json` names the run log
behind each width. See `docs/K1/ime_kernel_reproduction.md`.
